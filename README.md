🌐 Meu Portfólio

Site de portfólio pessoal de Victor dos Santos Costa, estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor em início de carreira. O projeto reúne currículo, formulário de contato, conteúdo multimídia e gráficos, tudo construído com HTML5, CSS3 e JavaScript puro, sem frameworks.

📄 Páginas
Página	Arquivo	Descrição
Início	index.html	Apresentação pessoal e resumo sobre mim
Currículo	curriculo.html	Qualificação, objetivo, educação, habilidades e cursos
Formulário	formulario.html	Formulário de contato com validação nativa do HTML5
Multimídia	multimidia.html	Vídeo incorporado do YouTube e mapa de localização (Google Maps)
Gráficos	graficos.html	Gráfico de barras em <canvas> e imagem vetorial em SVG
✨ Recursos
Layout responsivo (mobile-first) com CSS Grid e Flexbox e media queries para 600px, 768px e 1024px
Variáveis CSS (:root) para manter as cores padronizadas
Acessibilidade: lang="pt-BR", alt em imagens, label associado a cada campo, estilos de foco visíveis, classe .visually-hidden e rel="noopener noreferrer" em links externos
Validação de formulário com required, minlength, pattern e tipos de campo (email, tel)
Gráfico desenhado com Canvas API em JavaScript
Animações suaves com transition nos cards, botões e menu
Incorporação de vídeo e mapa via iframe com loading="lazy"
🛠️ Tecnologias
HTML5
CSS3
JavaScript (Canvas API)
