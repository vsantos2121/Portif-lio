## Sobre o projeto

Esse é o meu portfólio, criado durante o curso de **Análise e Desenvolvimento de Sistemas** na Faculdade Braz Cubas (Mogi das Cruzes/SP). A ideia foi juntar num só lugar o meu currículo, uma forma de contato e alguns exemplos de conteúdo multimídia e gráficos.

O layout é responsivo e funciona bem tanto no computador quanto no celular.

## Páginas

| Página | Arquivo | O que tem |
| --- | --- | --- |
| Início | `index.html` | Apresentação e resumo sobre mim |
| Currículo | `curriculo.html` | Formação, habilidades, cursos e contato |
| Formulário | `formulario.html` | Formulário de contato com validação |
| Multimídia | `multimidia.html` | Vídeo incorporado e mapa da minha cidade |
| Gráficos | `graficos.html` | Gráfico em canvas e imagem em SVG |

## Tecnologias

- **HTML5**: estrutura semântica das páginas
- **CSS3**: Grid, Flexbox, variáveis e media queries
- **JavaScript**: gráfico de barras desenhado com a Canvas API

## Como rodar

Não precisa instalar nada. É só clonar e abrir no navegador:

```bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
cd NOME-DO-REPOSITORIO
```

Depois abra o arquivo `index.html` com duplo clique.
